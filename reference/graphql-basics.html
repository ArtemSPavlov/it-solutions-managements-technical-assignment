Базовая шпаргалка

Минимальный словарь и синтаксис для чтения API цифровой визитки.

Модель выполнения

Схема описывает допустимые поля и типы. Запрос выбирает нужные поля. Resolver получает данные. Ответ повторяет форму selection set внутри data.

query BusinessCard {
  profile {
    name
    skills { name }
  }
}
{
  "data": {
    "profile": {
      "name": "Артём Павлов",
      "skills": [{ "name": "..." }]
    }
  }
}

Маркеры типов

String
Скалярное строковое значение; вложенный selection set не нужен и не разрешён.
String!
Non-Null string: сервер обещает строку, а не null.
[Skill!]!
Non-Null список Non-Null объектов Skill: всегда массив, возможно пустой; элементы не null.
DateTime
Nullable scalar: допустимы значение даты-времени и null. В проекте endedAt: null означает текущую работу.

Словарь

Schema — схема
Контракт API: типы, поля, аргументы и корневые операции, доступные клиенту.
SDL — Schema Definition Language
Синтаксис описания схемы, например type Profile { name: String! }. В проекте SDL генерируется из TypeScript.
Object type — объектный тип
Тип с набором полей, например Profile или Skill. Для него клиент строит вложенный selection set.
Scalar — скаляр
Листовое значение: String, Boolean, пользовательский DateTime и т. п.
Query — операция чтения
Корневая операция получения данных. В этом проекте доступна только Query.profile.
Selection set — набор выбранных полей
Содержимое фигурных скобок: какие поля вернуть для объектного значения.
Resolver
Функция получения значения поля. В NestJS корневой resolver объявлен методом ProfileResolver.profile().
Mutation / Subscription
Корневые операции записи и подписки на события. В текущей схеме проекта их нет.
Introspection
Запрос информации о самой схеме через служебные поля вроде __schema; используется GraphQL-инструментами.
