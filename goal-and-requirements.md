# Цифровая визитка

> Backend-приложение, которое представляет владельца как специалиста и демонстрирует качество инженерных решений.

## Overview

Приложение предоставляет публичный GraphQL API с данными владельца: профилем, навыками, опытом работы и проектами. Apollo Sandbox служит интерфейсом для изучения API.

## Capabilities

- Возвращать профиль владельца: имя, краткое описание и ссылки на GitHub, LinkedIn или другие профессиональные ресурсы.
- Возвращать связанные с профилем навыки.
- Возвращать опыт работы: компанию, должность, период и достижения.
- Возвращать проекты: название и ссылку на проект или репозиторий.
- Позволять получить профиль и выбранные вложенные данные одним GraphQL-запросом через Apollo Sandbox.
- Автоматически подготавливать базу данных и заполнять её данными владельца при запуске приложения.
- Разделять GraphQL API, бизнес-логику и доступ к данным; загружать вложенные данные без заведомо неоптимальных запросов к базе.
- Объяснять архитектурные решения и запуск проекта в `README.md`.

## Success Conditions

- После запуска из чистого окружения база данных готова без ручной инициализации, а API содержит данные владельца.
- Пример вложенного GraphQL-запроса возвращает профиль, навыки, опыт и проекты.
- Apollo Sandbox доступен для интерактивной проверки API.
- Структура приложения и запросы к базе данных позволяют объяснить границы ответственности и выбранную оптимизацию.
- Исходный код хранится в Git; приложение можно запустить с помощью Docker.

## Technology

| Aspect | Choice | Rationale |
| --- | --- | --- |
| Runtime | Node.js | Обязательная среда выполнения по условию задания. |
| Language | TypeScript | Обязательный язык; типизация поддерживает читаемость и сопровождение. |
| Framework | NestJS | Обязательный каркас приложения и границы модулей. |
| Database access | Prisma | Обязательный доступ к данным и управление схемой базы. |
| API | GraphQL | Обязательный контракт выборки профиля и вложенных данных. |
| Interactive API UI | Apollo Sandbox | Обязательный способ исследования API. |
| Packaging | Docker | Обязательное средство воспроизводимого запуска. |
| Version control | Git | Обязательный способ публикации исходного кода. |

## Alternatives Considered

- [haunguyendev/portfolio-v2](https://github.com/haunguyendev/portfolio-v2) — совпадает по NestJS, GraphQL и Prisma, но представляет собой монорепозиторий с frontend, CMS и аутентификацией; для этого задания достаточно компактного backend-only решения.
- [Prisma Examples: nest-graphql](https://github.com/prisma/prisma-examples/tree/latest/orm/nest-graphql) — официальный ориентир для code-first API и миграций, но без предметной модели визитки и отдельного акцента на загрузке вложенных данных.
- [sergio-jc/mock-shop-api](https://github.com/sergio-jc/mock-shop-api) — показывает request-scoped DataLoader для предотвращения N+1, однако его e-commerce-домен и инфраструктурные возможности шире текущей задачи; полезен как ориентир, а не как шаблон для копирования.
