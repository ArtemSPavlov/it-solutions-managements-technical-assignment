# Начальная точка: REST знаком, GraphQL почти нет

Пользователь сообщил, что знает REST, почти не знает GraphQL и хочет изучить его с нуля на примере проекта. Поэтому первый урок строит базовую модель «схема → запрос → resolver → ответ», а оптимизация загрузки и продвинутые возможности откладываются до подтверждённого понимания основ.
